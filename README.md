<h2>🎓 Frequently Asked Questions (FAQ)</h2>

<h3>Is ParticleEx safe to use with my saved games?</h3>
<p>Yes, 100%. ParticleEx only replaces graphical effect data (visually similar to texture replace mods). It does not change game code, missions, or save file formats. Your existing progress will load normally.</p>

<h3>Will this work with other mods I have installed?</h3>
<p>ParticleEx is designed to be compatible with most mods because it modifies the same particle configuration files that many visual mods use. However, if you have another mod that specifically changes particle effects too, they might conflict. In that case, install ParticleEx after any other mods and it should overwrite only particle settings.</p>

<h3>Can I uninstall ParticleEx?</h3>
<p>Yes. The installer adds an uninstall option. Go to "Control Panel" > "Programs and Features" (on Windows 10/11: Settings > Apps), find "ParticleEx," click it, and select "Uninstall." It will cleanly remove itself and restore the original PC particle files.</p>

<h3>I have the Steam version of GTA. Will this work?</h3>
<p>Yes, ParticleEx works with all versions: Steam, GOG, and retail disc editions. It handles the folder names for each easily.

<h3>My game crashes after installation. What should I do?</h3>
<p>The most common issue is that you pointed the installer to the wrong folder during setup. Uninstall using Control Panel, then reinstall and double-check that the path points to the folder containing your game executable (<code>gta3.exe</code> or <code>gta-vc.exe</code>). Also make sure you have the latest version of your game patched.</p>
